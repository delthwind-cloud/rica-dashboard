RACI 責任矩陣儀表板範例資料

每項任務對應各角色的 R / A / C / I，並自動檢查「一項任務只有一位 A」等規則。

  • RResponsible 負責執行
  • AAccountable 最終課責（每項任務僅一位）
  • CConsulted 事前諮詢
  • IInformed 事後告知

點一下儲存格可切換：空白 → R → A → A+R → C → I → 空白。編輯只存在目前頁面，請用「匯出 CSV」保存；點欄位標題可聚焦該角色。
