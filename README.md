# RACI 責任矩陣儀表板

純靜態網頁（HTML / CSS / JS，無建置步驟），以 GitHub Pages 發佈。

- 資料檔：`data/raci.csv`（第一欄任務、第二欄類別，其後每欄一個角色；儲存格填 `R` `A` `C` `I`，可組合如 `AR`，空白代表未參與）
- 功能：責任矩陣（可點擊編輯）、角色向量（各角色 R/A/C/I 任務數）、規則檢查（每項任務需恰有一位 A、至少一位 R）、CSV 匯入／匯出、深淺色
- 更新方式：修改 `data/raci.csv` 後 commit 並 push，網頁自動更新

目前 `data/raci.csv` 為範例資料，請換成實際內容。
